# AI Chatbot using Groq (LLaMA)

---

## 📌 Overview

This project is a **simple command-line AI chatbot** built using the **Groq API and LLaMA model**.

It allows users to ask questions and receive intelligent responses in real time using a powerful Large Language Model.

---

## 🚀 Features

- Interactive command-line chatbot  
- Real-time responses using LLaMA model  
- Simple and lightweight implementation  
- Continuous conversation loop until exit  
- Secure API key handling using `.env`  

---

## ⚙️ How It Works

- Takes user input from terminal  
- Sends the input to Groq API  
- Uses **LLaMA 3.3 70B Versatile model** for generating responses  
- Displays AI-generated output instantly  

---

## 🛠️ Tech Stack

- Python  
- Groq API  
- LLaMA Model  
- python-dotenv
